## **Тема**

Подключение к LLM через API Cloud.ru, базовые запросы и первичный поиск галлюцинаций

## **Цель работы**

Познакомиться с работой больших языковых моделей через API Cloud.ru, научиться отправлять запросы к нескольким моделям, сравнивать ответы на разные формулировки промптов и выявлять первые признаки ограничений LLM: неточности, выдуманные факты, чрезмерную уверенность и зависимость ответа от формулировки запроса.

**Теоретические сведения**

Большие языковые модели решают задачи генерации текста, объяснения понятий, суммаризации, перевода, ответа на вопросы, структурирования информации и анализа текста.

Качество ответа LLM зависит не только от выбранной модели, но и от формулировки промпта. Одна и та же задача может быть описана разными словами: «сделай резюме», «саммаризируй», «сократи», «выдели главное», «составь краткое содержание». Ответы модели при этом могут отличаться по длине, структуре, точности и полезности.

Также LLM могут допускать галлюцинации — выдавать неверную или неподтверждённую информацию как достоверную. Поэтому ответы модели необходимо проверять, особенно если в них есть даты, ссылки, имена, названия документов, числовые значения или конкретные факты.

**Задания к работе**

## **Задание 1\. Подготовка среды и подключение к Cloud.ru**

Что нужно сделать:

1. Установить Python и необходимые библиотеки.  
2. Получить API-ключ для работы с моделями Cloud.ru.  
3. Подключиться к Cloud.ru через OpenAI-совместимый API.  
4. Получить список доступных моделей.  
5. Выбрать минимум **две модели** для выполнения экспериментов.

Результат задания:

* в отчёте указан список доступных моделей;  
* выбраны минимум две модели;  
* приведён код подключения;  
* выполнен тестовый запрос к каждой выбранной модели.

**Задание 2\. Первый запрос к модели**

Отправьте в каждую выбранную модель простой запрос на объяснение понятия.

Запрос должен быть одинаковым для всех моделей.

После получения ответов сравните:

* насколько ответ понятный;  
* насколько он полный;  
* есть ли лишняя информация;  
* есть ли фактические ошибки;  
* какая модель ответила лучше.

Результат задания:

* сохранены ответы минимум двух моделей;  
* сделано краткое сравнение ответов;  
* указано, какая модель дала более качественный ответ и почему.

**Задание 3\. Эксперимент с разными формулировками одной задачи**

Выберите небольшой текст объёмом 1–2 страницы. Текст может быть связан с IT, искусственным интеллектом, базами данных, программированием, анализом данных или другой технической темой.

Нужно проверить, как модель реагирует на разные формулировки задачи суммаризации.

Составьте минимум **5 промптов**, которые требуют выполнить похожую задачу, но разными словами.

Например, смысл задачи может быть таким:

* сделать резюме текста;  
* саммаризировать текст;  
* кратко пересказать текст;  
* выделить главные мысли;  
* сократить текст;  
* составить краткое содержание;  
* объяснить основную идею текста.

Все промпты нужно отправить минимум в две выбранные модели.

Для каждого ответа оцените:

* длину ответа;  
* сохранение основного смысла;  
* наличие важных деталей;  
* появление лишней информации;  
* удобство структуры;  
* отличие ответа от других вариантов.

Результат задания:

* есть таблица с 5 формулировками промпта;  
* есть ответы минимум двух моделей на каждый промпт;  
* есть сравнение: какие слова в промпте дали более точный, краткий или полезный результат;  
* сделан вывод, какая формулировка оказалась наиболее удачной.

**Задание 4\. Эксперимент с ответами на вопросы по тексту**

Используйте тот же текст, что и в предыдущем задании.

Составьте минимум **3 вопроса по тексту**:

1. вопрос, на который ответ прямо есть в тексте;  
2. вопрос, на который можно ответить только после понимания смысла текста;  
3. вопрос, на который нельзя корректно ответить на основе данного текста.

Отправьте эти вопросы в выбранные модели.

Важно проверить, как модель ведёт себя в третьем случае: признаёт ли она, что в тексте недостаточно информации, или начинает придумывать ответ.

Результат задания:

* приведены 3 вопроса;  
* сохранены ответы моделей;  
* отмечено, где модель ответила по тексту, а где добавила информацию от себя;  
* сделан вывод о том, какая модель лучше работает с ограниченным контекстом.

**Задание 5\. Эксперимент с форматом ответа**

На основе выбранного текста или темы составьте несколько промптов, где требуется один и тот же смысл, но разный формат ответа.

Минимум нужно проверить 3 формата:

1. обычный текст;  
2. список;  
3. таблица или JSON.

Для каждого формата сравните:

* соблюдает ли модель требуемую структуру;  
* добавляет ли текст вне заданного формата;  
* удобно ли использовать результат;  
* теряется ли смысл при переходе к более строгому формату.

Результат задания:

* приведены промпты для разных форматов;  
* сохранены ответы моделей;  
* указано, какая модель лучше соблюдала формат;  
* сделан вывод, какой формат оказался наиболее удобным для анализа.

**Задание 6\. Первичный поиск галлюцинаций**

Составьте отдельный промпт, который провоцирует модель на выдачу конкретных фактов.

В ответе модели должны появиться проверяемые элементы:

* даты;  
* числа;  
* названия технологий;  
* имена авторов;  
* названия статей, книг, документов или стандартов;  
* ссылки;  
* утверждения о возможностях инструментов или моделей.

Отправьте этот промпт во все выбранные модели.

Из ответов каждой модели выберите минимум **3 проверяемых утверждения** и проверьте их вручную по открытым источникам.

Для каждого утверждения определите:

* подтверждается ли оно;  
* есть ли ошибка;  
* не является ли оно слишком точным без оснований;  
* не придумала ли модель источник, ссылку или факт;  
* не выдала ли модель предположение за факт.

Результат задания:

* есть промпт для поиска галлюцинаций;  
* выбраны минимум 3 утверждения от каждой модели;  
* выполнена ручная проверка;  
* оформлена таблица найденных ошибок или подтверждённых фактов.

**Задание 7\. Оценка качества ответов**

Для каждого основного промпта оцените ответы моделей по критериям.

| Критерий | Описание |
| ----- | ----- |
| Точность | нет ли фактических ошибок |
| Полнота | раскрыта ли задача полностью |
| Ясность | понятно ли сформулирован ответ |
| Следование инструкции | выполнила ли модель условия промпта |
| Структура | удобно ли читать и использовать ответ |
| Проверяемость | можно ли проверить ключевые утверждения |

Оценку можно ставить по шкале от 1 до 5\.

Итоговую таблицу можно оформить так:

| Модель | Промпт | Точность | Полнота | Ясность | Следование инструкции | Структура | Комментарий |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |

Результат задания:

* заполнена таблица оценки качества;  
* оценки сопровождаются краткими комментариями;  
* сделан вывод о сильных и слабых сторонах моделей.
