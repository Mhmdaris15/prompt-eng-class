## Тема

**Разработка и исследование RAG-системы для поиска и анализа научных публикаций**

## Цель работы

Научиться использовать внешние документы при генерации ответов языковой моделью. В ходе работы вы реализуете небольшой исследовательский ассистент: он будет находить научные публикации по вопросу, передавать их аннотации LLM и формировать ответ с указанием источников. Затем вы проверите качество поиска, достоверность утверждений и попробуете улучшить систему.

Основная часть программного кода дана в готовом Jupyter Notebook. Вам необходимо самостоятельно выбрать тему, подготовить исследовательские вопросы, разработать улучшенный RAG-промпт и проанализировать результаты экспериментов.

## Теоретические сведения

**Retrieval-Augmented Generation (RAG)** — подход, при котором языковая модель получает дополнительную информацию из внешних источников. В этой работе система сначала выбирает подходящие научные публикации, а затем использует их аннотации для ответа на вопрос.

**Эмбеддинг** — числовой вектор текста. Для поиска можно сравнивать эмбеддинг вопроса с эмбеддингами статей с помощью косинусной близости. При этом высокая близость не гарантирует, что документ действительно содержит ответ на вопрос.

**Контекст RAG** — выбранные фрагменты документов, которые передаются модели вместе с вопросом. В нашей лабораторной контекст состоит из аннотаций статей с их названиями, авторами и идентификаторами ArXiv.

Наличие источников не делает ответ автоматически верным: модель может найти неподходящие публикации, неверно интерпретировать аннотации или сослаться на источник, который не подтверждает её утверждение. Именно такие ошибки вам предстоит исследовать.

## Материалы и подготовка

Для работы необходимы Python 3.10+, Jupyter Notebook или Google Colab, персональный API-ключ курса и файл **dataset.csv**.

[Папка с датасетом и ноутбуко](https://disk.yandex.ru/d/cUfe2a48_HNp1w)м

Положите dataset.csv в ту же папку, что и Jupyter Notebook. В Google Colab файл необходимо загрузить в раздел «Файлы».

В итоговом датасете используются следующие столбцы:

| Поле | Содержание |
| :---- | :---- |
| article\_id | Идентификатор статьи ArXiv, например 0704.0001 |
| authors | Авторы |
| title | Название статьи |
| categories | Тематические коды |
| main\_category | Основная научная категория |
| other\_categories | Дополнительные категории |
| abstract | Аннотация статьи |
| year | Год |
| embedding\_bge\_m3 | Уже вычисленный эмбеддинг статьи |

Для получения эмбеддинга вопроса используется модель cloud-bge/BAAI/bge-m3 и запрос requests.post на https\://proxy-prompts.aiclab.tech/v1/embeddings с заголовком x-bf-vk.

### Задание 3\. Выбор собственной темы

Выберите научное направление, представленное в датасете. Измените переменную KEYWORD в Notebook: поиск ведётся по названиям, аннотациям и категориям. В отчёте укажите выбранную тему, ключевое слово, количество просмотренных записей и количество отобранных публикаций. Объясните, какие ограничения возникают, когда поиск выполняется только по тематическому подмножеству документов.

### Задание 4\. Работа с готовыми эмбеддингами

### Задание 5\. Исследовательские вопросы и оценка поиска

Составьте пять собственных исследовательских вопросов:

Для каждого вопроса найдите три публикации с помощью search\_articles(). Вручную прочитайте найденные аннотации и поставьте оценку релевантности: **0** — не помогает ответить; **1** — частично полезна; **2** — содержит информацию по вопросу. Обоснуйте все оценки.

### Задание 7\. Проектирование RAG-промпта

Сначала получите ответ с простым промптом, содержащим вопрос и аннотации трёх найденных статей. После этого разработайте **свою улучшенную инструкцию** в переменной MY\_RAG\_INSTRUCTION.

Продумайте роль модели, структуру ответа, правила ссылок на источники \[S1\], \[S2\], действия при недостатке информации, запрет на вымышленные факты и ограничения на выводы, не подтверждённые аннотациями. Попробуйте обе версии на двух вопросах, сравните и объясните эффект изменений.

### Задание 8\. Сравнение ответов с RAG и без RAG

Используя одну и ту же основную LLM, получите два ответа на все пять вопросов: обычный ответ и ответ с RAG на основе трёх найденных статей.

Выберите **один успешный** и **один проблемный** случай. Объясните, какая информация из статей помогла модели или почему RAG не дал улучшения.

### Задание 9\. Влияние количества и качества контекста

### Задание 10\. Проверка утверждений по источникам
