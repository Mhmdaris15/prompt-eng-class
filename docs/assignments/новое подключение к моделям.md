# **Обновленное подключение к моделям**

Для выполнения задания необходимо обращаться к языковым моделям через API курса.

Теперь используется **не общий ключ Cloud.ru**, а **личный ключ**.

У каждого свой ключ вида:

sk-bf-...

## **Важно**

Старый общий ключ Cloud.ru больше использовать не нужно.

Новый API работает через адрес:

https\://proxy-prompts.aiclab.tech/v1

# **1\. Что нужно установить**

Для работы понадобится Python 3.10+ и библиотека `openai`.

Установите библиотеку:

pip install openai

Если планируется хранить ключ в `.env`\-файле, дополнительно установите:

pip install python-dotenv

# **2\. API-ключ**

Для обращения к моделям используется ваш личный API-ключ.

Пример ключа:

sk-bf-ВАШ-КЛЮЧ

Ключ нельзя:

* публиковать в открытых репозиториях;  
* отправлять в общий чат;  
* вставлять в отчёт;  
* передавать другим студентам.

Если другой человек использует ваш ключ, токены будут списываться с вашего лимита.

# **3\. Базовый адрес API**

API курса поддерживает OpenAI-совместимый формат запросов.

Базовый адрес API:

https\://proxy-prompts.aiclab.tech/v1

Для отправки сообщений используется метод:

/v1/chat/completions

Полный адрес:

https\://proxy-prompts.aiclab.tech/v1/chat/completions

**4\. Проверка доступных моделей**

Перед запуском эксперимента можно посмотреть список моделей, доступных вашему ключу.

В терминале выполните:

| curl \-sS \\  'https\://proxy-prompts.aiclab.tech/usage' \\  \-H 'Authorization: Bearer sk-bf-ВАШ-КЛЮЧ' \\\| jq \-r '.provider\_configs\[\].allowed\_models\[\]' |
| :---- |

Вместо:

sk-bf-ВАШ-КЛЮЧ

вставьте свой настоящий ключ.

Пример результата:

Qwen/Qwen3-30B-A3B  
GigaChat/GigaChat-3-Pro  
ai-sage/GigaChat3-10B-A1.8B  
openai/gpt-4.1-mini

В задании можно использовать только модели из списка, доступного вашему ключу.

**5\. Проверка лимита по каждой модели**

У каждой модели есть свой лимит токенов.

Чтобы посмотреть лимит, уже использованные токены и остаток, выполните:

| curl \-sS \\  'https\://proxy-prompts.aiclab.tech/usage' \\  \-H 'Authorization: Bearer sk-bf-ВАШ-КЛЮЧ' \\\| jq \-r '  \["MODEL", "LIMIT", "USED", "LEFT"\],  (    .model\_configs    \| sort\_by(.model\_name)\[\]    \| \[        .model\_name,        .rate\_limit.token\_max\_limit,        (.rate\_limit.token\_current\_usage // 0),        (          .rate\_limit.token\_max\_limit \-          (.rate\_limit.token\_current\_usage // 0\)        )      \]  )  \| @tsv' |
| :---- |

Пример результата:

MODEL                         LIMIT     USED    LEFT  
Qwen/Qwen3-30B-A3B             266000    1200    264800  
GigaChat/GigaChat-3-Pro        228000    500     227500  
openai/gpt-4.1-mini             76000    0        76000

Где:

MODEL — название модели  
LIMIT — общий лимит токенов на эту модель  
USED  — сколько токенов уже использовано  
LEFT  — сколько токенов осталось

Если появляется ошибка:

jq: command not found

можно выполнить команду без `jq`:

| curl \-sS \\  'https\://proxy-prompts.aiclab.tech/usage' \\  \-H 'Authorization: Bearer sk-bf-ВАШ-КЛЮЧ' |
| :---- |

Ответ будет менее красивым, но в нём всё равно будут доступны модели и лимиты.

# **10\. Частые ошибки**

## **`401 Unauthorized`**

Проблема с ключом.

Проверьте, что ключ указан правильно:

api\_key="sk-bf-..."

Или в curl:

\-H "Authorization: Bearer sk-bf-..."

Слово `Bearer` обязательно.

## **`403 Forbidden`**

Запрос запрещён.

Возможные причины:

* модель недоступна вашему ключу;  
* вы указали модель не из списка доступных;  
* доступ к модели ограничен.

Проверьте список доступных моделей через `/usage`.

## **`429 Too Many Requests`**

Слишком много запросов за короткое время или достигнут лимит.

Что сделать:

* подождать;  
* уменьшить количество параллельных запросов;  
* проверить остаток токенов;  
* использовать более простую модель.

## **`400 Bad Request`**

Если при подключении к модели возникает ошибка 400, то в модели указывать строку типа "model": "cloud/openai/gpt-oss-120b"

Чаще всего:

* ошибка в JSON;  
* неправильное название модели;  
* неправильно передан `messages`;  
* модель не поддерживает какой-то параметр.

## **`500`, `502`, `503`**

Ошибка сервера или модели.

Если ошибка повторяется, отправьте преподавателю:

Название модели:  
HTTP status:  
Текст ошибки:  
Время запроса:

Ключ отправлять не нужно.
